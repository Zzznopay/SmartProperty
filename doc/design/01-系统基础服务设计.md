# 系统基础服务设计 (smart-property-system)

## 一、服务概述

### 1.1 服务职责

系统基础服务负责整个平台的基础支撑功能，包括：
- **认证授权**：用户登录、Token管理、权限验证、验证码
- **系统管理**：用户、角色、菜单、部门、字典、公司、日志
- **文件管理**：文件上传、下载、网盘
- **报表服务**：报表查询、统计分析、数据导出

### 1.2 业务模块映射

| 业务模块 | 功能点 |
|---------|--------|
| 我的工作 | 我的消息、我的邮件、我的短信、我的日程、我的记事本、我的网盘 |
| 系统管理 | 企业档案、部门管理、职位管理、角色管理、用户管理、登录日志、操作日志 |
| 参数配置 | 模块管理、参数选项、自定义类型、工作日设置 |
| 手机短信 | 常用短信、短信统计、短信授权 |
| 报表查询 | 房产查询、业主查询、费用明细、欠费查询、收费统计 |

## 二、数据库设计

### 2.1 用户表 (sys_user)

```sql
CREATE TABLE sys_user (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID',
    company_id BIGINT UNSIGNED NOT NULL COMMENT '物业公司ID',
    dept_id BIGINT UNSIGNED DEFAULT NULL COMMENT '部门ID',
    username VARCHAR(64) NOT NULL COMMENT '用户名',
    password VARCHAR(128) NOT NULL COMMENT '密码(BCrypt加密)',
    real_name VARCHAR(64) DEFAULT NULL COMMENT '真实姓名',
    phone VARCHAR(128) DEFAULT NULL COMMENT '手机号(加密存储)',
    phone_mask VARCHAR(32) DEFAULT NULL COMMENT '手机号(脱敏)',
    email VARCHAR(128) DEFAULT NULL COMMENT '邮箱',
    avatar VARCHAR(512) DEFAULT NULL COMMENT '头像URL',
    gender TINYINT UNSIGNED DEFAULT 0 COMMENT '性别(0未知 1男 2女)',
    status TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '状态(0禁用 1启用)',
    login_ip VARCHAR(64) DEFAULT NULL COMMENT '最后登录IP',
    login_time DATETIME DEFAULT NULL COMMENT '最后登录时间',
    remark VARCHAR(500) DEFAULT NULL COMMENT '备注',
    create_by VARCHAR(64) DEFAULT NULL COMMENT '创建者',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by VARCHAR(64) DEFAULT NULL COMMENT '更新者',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '是否删除(0否 1是)',
    PRIMARY KEY (id),
    UNIQUE KEY uk_username (username),
    KEY idx_company_id (company_id),
    KEY idx_dept_id (dept_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

## 三、接口设计

### 3.1 认证接口

#### 3.1.1 用户名密码登录

```
POST /api/v1/auth/login
```

**请求参数：**

```json
{
    "username": "admin",
    "password": "123456",
    "captchaCode": "abcd",
    "captchaKey": "uuid-xxxx"
}
```

**响应数据：**

```json
{
    "code": "00000",
    "data": {
        "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
        "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
        "expiresIn": 7200,
        "userInfo": {
            "id": 1,
            "username": "admin",
            "realName": "管理员",
            "roles": ["admin"],
            "permissions": ["*:*:*"]
        }
    }
}
```

#### 3.1.2 刷新Token

```
POST /api/v1/auth/refresh
```

#### 3.1.3 用户注销


## 四、业务流程设计

### 4.1 用户登录流程

```
客户端 → 网关 → 验证码校验 → 查询用户 → 验证密码 → 生成JWT → 缓存Token → 返回
```

### 4.2 权限验证流程

```
请求 → 网关拦截 → 解析Token → 验证有效性 → 获取权限 → 验证接口权限 → 转发/拒绝
```

### 4.3 文件上传流程

```
客户端 → 文件校验 → 计算MD5 → 上传MinIO → 保存元数据 → 返回URL
```

## 五、复杂SQL示例

### 5.1 用户列表查询

```xml
<!-- mapper/SysUserMapper.xml -->
<select id="selectUserPage" resultType="com.smart.property.system.vo.UserVO">
    SELECT
        u.id, u.username, u.real_name, u.phone_mask, u.email,
        u.gender, u.status, u.create_time, d.dept_name
    FROM sys_user u
    LEFT JOIN sys_dept d ON u.dept_id = d.id AND d.is_deleted = 0
    WHERE u.is_deleted = 0
        AND u.company_id = #{companyId}
        <if test="username != null and username != ''">
            AND u.username LIKE CONCAT('%', #{username}, '%')
        </if>
        <if test="status != null">
            AND u.status = #{status}
        </if>
    ORDER BY u.create_time DESC
</select>
```

### 5.2 收费统计查询

```xml
<!-- mapper/ReportMapper.xml -->
<select id="selectPaymentStatistics" resultType="com.smart.property.report.vo.PaymentStatisticsVO">
    SELECT
        DATE_FORMAT(p.pay_time, '%Y-%m') AS month,
        SUM(p.actual_amount) AS totalAmount,
        COUNT(DISTINCT p.owner_id) AS ownerCount
    FROM finance_payment p
    WHERE p.company_id = #{companyId}
        AND p.is_deleted = 0
        AND p.status = 1
        AND DATE_FORMAT(p.pay_time, '%Y-%m') BETWEEN #{startMonth} AND #{endMonth}
    GROUP BY DATE_FORMAT(p.pay_time, '%Y-%m')
    ORDER BY month
</select>
```

## 六、缓存设计

| Key格式 | 说明 | 过期时间 |
|--------|------|---------|
| `sys:user:{userId}` | 用户信息 | 30分钟 |
| `sys:user:perms:{userId}` | 用户权限 | 30分钟 |
| `sys:dict:{dictType}` | 字典数据 | 24小时 |
| `auth:token:{userId}` | 用户Token | 2小时 |
| `auth:captcha:{key}` | 验证码 | 5分钟 |
