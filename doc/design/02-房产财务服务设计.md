# 房产财务服务设计 (smart-property-property)

## 一、服务概述

### 1.1 服务职责

房产财务服务负责物业管理的核心业务，包括：
- **房产管理**：小区、楼宇、单元、房间
- **业主管理**：业主档案、家庭成员、验房、装修
- **租赁管理**：租户、合同、租金、转兑
- **收费管理**：费项设置、物业费生成、收费、退款
- **车位管理**：车位维护、销售、出租、缴费
- **预收款管理**：预收、抵扣、余额

### 1.2 业务模块映射

| 业务模块 | 功能点 |
|---------|--------|
| 房产管理 | 新增住宅向导、住宅维护、住宅批量增加、住宅查询、房产向导、房产维护 |
| 销售管理 | 房产销售、销售合同、物业验房、物业接管、图纸上传 |
| 业主管理 | 业主验房、业主装修、业主入住、业主投诉、请修管理 |
| 费项设置 | 常规费项、公摊费项、临时费项、临客费项、物业费分布 |
| 票据管理 | 票据维护、票据分配、票据作废 |
| 收费管理 | 生成物业费、收取物业费、临时收费、退款、作废 |
| 车位管理 | 车位维护、车位销售、车位出租、车位缴费 |
| 租赁管理 | 租户管理、租赁合同、租金收取、租户转兑 |

## 二、数据库设计

### 2.1 小区表 (property_community)

```sql
CREATE TABLE property_community (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '小区ID',
    company_id BIGINT UNSIGNED NOT NULL COMMENT '物业公司ID',
    community_name VARCHAR(128) NOT NULL COMMENT '小区名称',
    community_code VARCHAR(64) NOT NULL COMMENT '小区编码',
    address VARCHAR(256) DEFAULT NULL COMMENT '小区地址',
    area DECIMAL(12,2) DEFAULT NULL COMMENT '占地面积(㎡)',
    building_count INT UNSIGNED DEFAULT 0 COMMENT '楼宇数量',
    room_count INT UNSIGNED DEFAULT 0 COMMENT '房间数量',
    property_fee DECIMAL(10,4) DEFAULT NULL COMMENT '物业费单价(元/㎡/月)',
    contact_name VARCHAR(64) DEFAULT NULL COMMENT '负责人',
    contact_phone VARCHAR(32) DEFAULT NULL COMMENT '联系电话',
    status TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '状态(0停用 1正常)',
    remark VARCHAR(500) DEFAULT NULL COMMENT '备注',
    create_by VARCHAR(64) DEFAULT NULL COMMENT '创建者',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by VARCHAR(64) DEFAULT NULL COMMENT '更新者',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '是否删除(0否 1是)',
    PRIMARY KEY (id),
    UNIQUE KEY uk_community_code (community_code),
    KEY idx_company_id (company_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='小区表';
```

### 4.2 欠费汇总查询

```xml
<!-- mapper/FinanceLedgerMapper.xml -->
<select id="selectArrearsSummary" resultType="com.smart.property.finance.vo.ArrearsSummaryVO">
    SELECT
        r.id AS roomId, r.room_code, r.room_no,
        c.community_name, b.building_name,
        o.owner_name, o.phone_mask AS ownerPhone,
        SUM(l.amount) AS totalAmount,
        SUM(l.paid_amount) AS paidAmount,
        SUM(l.amount - l.paid_amount) AS arrearsAmount,
        SUM(l.late_fee) AS totalLateFee
    FROM finance_ledger l
    INNER JOIN property_room r ON l.room_id = r.id
    INNER JOIN property_community c ON r.community_id = c.id
    INNER JOIN property_building b ON r.building_id = b.id
    INNER JOIN property_owner o ON l.owner_id = o.id
    WHERE l.company_id = #{companyId} AND l.is_deleted = 0 AND l.status IN (1, 2)
    GROUP BY r.id, r.room_code, r.room_no, c.community_name, b.building_name, o.owner_name, o.phone_mask
    HAVING arrearsAmount > 0
    ORDER BY arrearsAmount DESC
</select>
```

### 4.3 租赁合同到期提醒

```xml
<select id="selectExpiringContracts" resultType="com.smart.property.property.vo.LeaseContractVO">
    SELECT
        lc.id, lc.contract_no, lc.end_date,
        r.room_no, t.tenant_name, t.phone_mask AS tenantPhone,
        DATEDIFF(lc.end_date, CURDATE()) AS daysRemaining
    FROM property_lease_contract lc
    INNER JOIN property_room r ON lc.room_id = r.id
    INNER JOIN property_tenant t ON lc.tenant_id = t.id
    WHERE lc.status = 2 AND lc.is_deleted = 0 AND lc.company_id = #{companyId}
        AND lc.end_date BETWEEN CURDATE() AND DATE_ADD(CURDATE(), INTERVAL #{days} DAY)
    ORDER BY lc.end_date ASC
</select>
```
